# پاکیار | PakYar

نمونه‌کار سامانهٔ مدیریت نظافت، چک‌لیست‌های شیفت، مصرف اقلام و تقسیم کار در محیط‌های خدماتی.

این مخزن نسخهٔ نمایشی و عمومی پروژه است. **هیچ پایگاه‌داده، حساب کاربری، رمز، پیام خصوصی، عکس آپلودشده یا اطلاعات واقعی کارکنان همراه آن نیست.** برای نمایش یا توسعه استفاده کنید؛ پیش از هر استفادهٔ واقعی، امنیت، حریم خصوصی، دسترسی‌ها و نیازهای سازمانی باید جداگانه بررسی شوند.

## امکانات نمونه

- رابط فارسی و راست‌چین، با نمایش تاریخ شمسی و ساعت ایران
- نقش‌های کاربری و دسترسی‌های محدودشده بر اساس بخش
- ثبت و پیگیری گزارش‌ها و چک‌لیست‌های نظافت
- ثبت اقلام مصرفی و گزارش‌گیری
- نمودارها و خروجی‌های مدیریتی
- یادآورها و اعلان‌های داخل برنامه
- نگهداری داده در رایانهٔ اجراکننده؛ مخزن عمومی شامل دادهٔ اجرایی نیست

## اجرای نمایشی در ویندوز

به Python 3.11 یا جدیدتر نیاز است. در پوشهٔ این پروژه، PowerShell را باز و این دستورها را اجرا کنید:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m core.create_admin
python run_pakyar.py
```

هنگام ساخت حساب مدیر، رمز را در پنجرهٔ ترمینال وارد کنید؛ رمز را در فایل کد ننویسید. سپس مرورگر را روی `http://127.0.0.1:5000` باز کنید.

## حریم خصوصی و انتشار

- دیتابیس و کلید برنامه در `instance/` ساخته می‌شوند و نباید به گیت‌هاب ارسال شوند.
- فایل‌های آپلودشده در `static/uploads/` نادیده گرفته می‌شوند.
- اطلاعات سلامت، مشخصات فردی و شکایت‌های کاری واقعی را در نسخهٔ عمومی یا تصاویر نمایشی قرار ندهید.
- از رمزهای آزمایشیِ قابل حدس استفاده نکنید و رمزها را با دیگران به اشتراک نگذارید.

## وضعیت

این مخزن نمونه‌کار است؛ به معنی تأیید امنیتی، گواهی پزشکی/قانونی یا آمادگی برای استقرار در سازمان نیست.
